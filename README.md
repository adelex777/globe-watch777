# Globe Watch – วิธีติดตั้ง

1. สร้าง repo บน GitHub (แนะนำแบบ public เพื่อให้ GitHub Actions ใช้ฟรีไม่จำกัด) แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (รวมโฟลเดอร์ .github)
2. Settings → Secrets and variables → Actions → New repository secret
   - ANTHROPIC_API_KEY (จาก console.anthropic.com)
   - TELEGRAM_BOT_TOKEN และ TELEGRAM_CHAT_ID (ไม่บังคับ ใช้ส่งแจ้งเตือนแดง สร้างบอทผ่าน @BotFather)
3. Settings → Pages → Deploy from branch → main / root เพื่อเปิดหน้าเว็บ
4. แท็บ Actions → เลือก scheduled → Run workflow เพื่อทดสอบรอบแรก

## ตารางเวลา (เวลาไทย)
- scheduled: 07:00, 12:00, 18:00 (cron เป็น UTC: 0 0,5,11 * * *)
- watch: ทุกชั่วโมง ตรวจข่าวพุ่ง ถ้าเกิน SPIKE_THRESHOLD (ค่าเริ่มต้น 8 บทความ/ชม.) จึงเรียก AI ประเมินใหม่เฉพาะประเทศนั้น
- ประเทศที่เปลี่ยนเป็นแดงจะส่งแจ้งเตือน Telegram ทันที (ครั้งเดียวต่อการเปลี่ยนสถานะ)

## ปรับแต่ง
- เพิ่ม/ลดประเทศ: แก้ scripts/countries.json (และ data/data.json ถ้าต้องการให้ขึ้นทันที)
- เปลี่ยนโมเดล: ตั้ง env MODEL
- GitHub อาจเริ่ม cron ช้าไปหลายนาที

## หัวข้อในการ์ดแต่ละประเทศ
การเงิน · สงคราม/ความมั่นคง · การปกครอง · ดอกเบี้ยนโยบายของธนาคารกลาง · ภาพรวมตลาดหุ้น
(ดอกเบี้ยและตลาดหุ้นอัปเดตเฉพาะรอบ scheduled ส่วนรอบ watch จะคงค่าเดิมไว้ ตัวเลขมาจากพาดหัวข่าว ถ้าข่าวไม่ระบุจะขึ้นว่าไม่พบข้อมูล)

## เปิดหน้าเว็บ
อย่าดับเบิลคลิกไฟล์ index.html โดยตรง เบราว์เซอร์จะบล็อกการโหลด data/data.json ทำให้เห็นแค่ข้อมูลตัวอย่าง
ให้เปิดผ่าน GitHub Pages หรือรันในเครื่องด้วย: python3 -m http.server แล้วเข้า http://localhost:8000

## เนื้อหาละเอียดและตัวเลข (เวอร์ชันล่าสุด)
- 📰 เกิดอะไรขึ้น: บทความสรุป 6-10 ประโยค (วันที่ ผู้เกี่ยวข้อง ตัวเลข สาเหตุ ผลต่อประชาชน) เขียนโดย Claude จากพาดหัวข่าว + การค้นเว็บ
- 🏦 ดอกเบี้ยนโยบาย: ตัวเลข + มติล่าสุด + ลิงก์แหล่งที่มา (Claude ค้นจากเว็บธนาคารกลางหรือสื่อที่เชื่อถือได้ ถ้ายืนยันไม่ได้จะไม่แสดงตัวเลข)
- 📈 ตลาดหุ้น: ระดับดัชนีและ +/- % ของวันซื้อขายล่าสุด ดึงเป็นตัวเลขตรงจาก Yahoo Finance (endpoint ไม่เป็นทางการ อาจเปลี่ยนหรือถูกจำกัดได้) ส่วนคำอธิบายสาเหตุมาจากข่าว
  สัญลักษณ์ดัชนีอยู่ใน countries.json ช่อง ysym ประเทศที่ว่างไว้จะไม่มีตัวเลข ตรวจ/แก้สัญลักษณ์ได้ตามต้องการ

## ตัวแปรปรับแต่ง (env ใน workflow)
- WEB_SEARCH=1 (ค่าเริ่มต้น) ให้ Claude ค้นเว็บ; ตั้ง 0 เพื่อประหยัดค่าใช้จ่าย แต่เนื้อหาจะสั้นลงและไม่มีตัวเลขดอกเบี้ยที่ยืนยันแล้ว
- WEB_USES=3 จำนวนครั้งค้นเว็บสูงสุดต่อประเทศต่อรอบ
- ต้องเปิดใช้ web search tool ในองค์กร/โปรเจกต์ที่ใช้ API key ที่ Anthropic Console และค่าค้นเว็บคิดแยก ตรวจราคาล่าสุดก่อนใช้
- ค่าใช้จ่ายรวมต่อวัน = 34 ประเทศ × 3 รอบ × (token + ค้นเว็บ) ถ้าสูงไป ลดจำนวนประเทศใน countries.json หรือใช้ WEB_SEARCH=0 กับรอบกลางวัน

## หัวข้อไซเบอร์ (เพิ่มล่าสุด)
🛡️ ไซเบอร์ · ธนาคาร/ระบบชำระเงิน/ระบบรัฐ: ดึงข่าวแฮก ข้อมูลรั่ว แรนซัมแวร์ ระบบล่ม ของแต่ละประเทศ (รอบ scheduled เรียก GDELT เพิ่มอีก 1 ชุดต่อประเทศ ใช้เวลาเพิ่มราว 3 นาทีต่อรอบ)
ตัวเฝ้าเหตุด่วนนับคำว่า cyberattack เป็นสัญญาณข่าววิกฤตด้วย

## หัวข้อเพิ่มเติม (เวอร์ชันล่าสุด)
- 💱 ค่าเงิน: อัตราแลกเปลี่ยนและ +/- % ตรงจาก Yahoo Finance (ช่อง fxsym/fxlabel ใน countries.json; ค่าเงินที่ผูกกับดอลลาร์อาจนิ่งมาก) + คำอธิบายสาเหตุ
  เงินเฟ้อ: ตัวเลขล่าสุดมาจากการค้นเว็บของ Claude พร้อมลิงก์ ถ้ายืนยันไม่ได้จะไม่แสดง
- ⛽ พลังงาน: ราคา Brent โลก (ตัวเลขตรง ใช้ร่วมทุกประเทศ) + ผลต่อค่าน้ำมัน/ค่าไฟของประชาชนในประเทศนั้นจากข่าว
- 🌪️ ภัยพิบัติธรรมชาติ: แผ่นดินไหว น้ำท่วม พายุ ไฟป่า ภัยแล้ง ฯลฯ ภัยพิบัติใหญ่ที่กระทบคนจำนวนมากนับเป็นปัจจัยระดับสีแดง และตัวเฝ้าเหตุด่วนนับ earthquake/tsunami เป็นสัญญาณ

## เวลา/โควตา
รอบ scheduled ตอนนี้เรียก GDELT 5 ชุดต่อประเทศ ใช้เวลาราว 15-16 นาทีต่อรอบ (ตั้ง timeout ไว้ 60 นาที) รวม 3 รอบต่อวันราว 50 นาที/วัน ใช้ได้สบายใน repo แบบ public ถ้าเป็น private ให้เช็กโควตา Actions ก่อน

## ลูกโลกสมจริง + แท็บ (เวอร์ชันล่าสุด)
- ลูกโลกวาดด้วย canvas: บรรยากาศเรืองแสง แสงเงา เส้นขอบประเทศ พื้นหลังดวงดาว ซูมได้ด้วยล้อเมาส์หรือปุ่ม ＋ －
- ประเทศที่อยู่ในระบบถูกระบายตามระดับสี (แดงกะพริบ) แตะที่ตัวประเทศหรือจุดก็ได้ ประเทศที่ไม่มีในระบบแตะแล้วจะบอกว่ายังไม่มีข้อมูล ชื่อภาษาไทยของประเทศอื่นมาจาก Intl ของเบราว์เซอร์ (ขึ้นเมื่อซูมเข้า)
- แผนที่ประเทศโหลดจาก world.json ข้าง index.html ก่อน ถ้าไม่มีจะโหลดจาก cdn.jsdelivr.net (world-atlas@2.0.2/countries-110m.json) ถ้าโหลดไม่ได้เลยจะแสดงเฉพาะจุดประเทศ
  ถ้าต้องการใช้ออฟไลน์ ให้ดาวน์โหลดไฟล์ countries-110m.json แล้วเปลี่ยนชื่อเป็น world.json วางข้าง index.html
- การ์ดแบ่งเป็น 3 แท็บ: 📰 ข่าว (บทความ+ลิงก์ต้นทาง) / 💰 การเงิน (ดอกเบี้ย หุ้น ค่าเงิน เงินเฟ้อ พลังงาน) / ⚠️ ความเสี่ยง (สงคราม การปกครอง ไซเบอร์ ภัยพิบัติ)

## การแจ้งเตือนการอัปเดต (เวอร์ชันล่าสุด)
- ทุกรอบ ระบบบันทึกลง data/log.json ว่าประเทศไหนเปลี่ยนอะไร ตอนกี่โมง (เวลาไทย) เช่น ระดับสี ดอกเบี้ย เงินเฟ้อ หุ้นขยับตั้งแต่ ±2% ค่าเงินตั้งแต่ ±1.5% เหตุไซเบอร์/ภัยพิบัติใหม่ และสรุปท้ายรอบว่าตรวจกี่ประเทศ เปลี่ยนกี่ประเทศ (เก็บย้อนหลังสูงสุด 600 รายการ)
- หน้าเว็บ: ปุ่ม 🔔 การอัปเดต แสดงรายการแยกตามวัน พร้อมตัวเลขบอกจำนวนที่ยังไม่ได้อ่าน กดรายการเพื่อไปที่ประเทศนั้น มีแถบเตือนสีแดงเมื่อมีประเทศขึ้นแดงใหม่ และดึงข้อมูลใหม่เองทุก 5 นาทีโดยไม่ต้องรีเฟรช ปุ่มเปิดแจ้งเตือนบนเบราว์เซอร์จะเด้งแจ้งเมื่อมีประเทศขึ้นแดงใหม่ขณะเปิดหน้านี้ค้างไว้
- Telegram: หลังจบทุกรอบ scheduled (เช้า กลางวัน เย็น) ส่งข้อความสรุปว่าอัปเดตอะไรบ้าง ปิดได้โดยตั้ง DIGEST=0 ส่วนประเทศที่ขึ้นแดงยังแจ้งทันทีแยกต่างหากเหมือนเดิม
- ข้อควรรู้: รายการ "ข่าวใหม่" นับจากลิงก์ข่าวที่ต่างจากรอบก่อน จึงเกิดแทบทุกรอบ จะไม่ถูกลงเป็นรายการของประเทศ นอกจากมีการเปลี่ยนแปลงสำคัญอื่นด้วย

## เกณฑ์สีกรณีไซเบอร์ (ธนาคาร/โบรกเกอร์/ระบบชำระเงิน)
- แดง: กระทบระดับประเทศ เช่น ระบบชำระเงินหรือธนาคารใหญ่ล่มหลายวัน เงินถูกขโมยหรือแช่แข็งวงกว้าง ตลาดหลักทรัพย์ต้องหยุดซื้อขาย
- ส้ม: ธนาคาร โบรกเกอร์ หรือตลาดรายใหญ่ถูกเจาะหรือล่ม กระทบลูกค้าจำนวนมาก เช่น ข้อมูลรั่วหลายล้านราย มิจฉาชีพระบาด ล่มเป็นชั่วโมง
- เขียว (ไม่เปลี่ยนสี): เหตุเล็กหรือเฉพาะจุด ควบคุมได้เร็ว
- สีของแต่ละประเทศประเมินภาพรวมทั้งประเทศ โบรกเกอร์เจ้าเดียวถูกแฮกจึงมักไม่ทำให้ทั้งประเทศเปลี่ยนสี แต่จะขึ้นในแท็บความเสี่ยงและรายการอัปเดต
- นี่เป็นแนวทางในคำสั่งที่ให้โมเดล ผลจริงขึ้นกับดุลยพินิจของโมเดล ควรตรวจผลช่วงแรก

## เกณฑ์สีกรณีโจมตี (ใครยิงอะไรใส่ใคร)
สีของประเทศวัดผลกระทบต่อประชาชน "ภายในประเทศนั้น" ผู้โจมตีกับผู้ถูกโจมตีจึงได้สีต่างกันได้
- ประเทศที่ถูกโจมตี: แดง เมื่อพื้นที่ชุมชนหรือโครงสร้างพื้นฐานพลเรือนถูกโจมตีซ้ำหรือในวงกว้าง (โจมตีทางอากาศ ขีปนาวุธ ปืนใหญ่ โดรนใส่เมือง ผู้เสียชีวิตพลเรือนมาก ผู้พลัดถิ่น ไฟฟ้า/น้ำดับ) หรือมีการใช้อาวุธนิวเคลียร์/เคมี/ชีวภาพ; ส้ม เมื่อเป็นเหตุเดี่ยว โจมตีเป้าหมายทหาร ปะทะชายแดน หรือระเบิดครั้งเดียวผู้เสียชีวิตน้อย
- ประเทศผู้โจมตี: ส้มเป็นส่วนใหญ่ (เกณฑ์ทหาร เสี่ยงถูกตอบโต้ ถูกคว่ำบาตร) แดงเฉพาะเมื่อดินแดนหรือประชาชนของตนเองถูกโจมตีวงกว้างด้วย
- ประเทศที่แค่ส่งอาวุธ เงิน หรือสนับสนุนทางการทูต: ไม่เปลี่ยนสีจากเหตุนี้อย่างเดียว
- ก่อการร้าย/ระเบิดในเมืองซ้ำๆ: ส้ม ขึ้นแดงเมื่อเป็นการโจมตีต่อเนื่องและมีผู้เสียชีวิตมาก
- ขู่โจมตีหรือระดมพลโดยยังไม่มีการยิง: ส้มอย่างมาก
ทุกเหตุการณ์ในแท็บความเสี่ยงแสดงเป็นการ์ด: ผู้โจมตี → เป้าหมาย อาวุธ พื้นที่ ผลกระทบ และสถานะการระบุฝ่าย (ยืนยันจากหลายแหล่ง / ฝ่ายหนึ่งกล่าวอ้าง / ยังไม่ยืนยัน) พร้อมเหตุผลของสีใต้ป้ายสี เหตุที่รุนแรงระดับ 1 ใหม่จะลงรายการอัปเดตด้วย

## ตรวจระบบเมื่อไม่เห็นข้อมูลอัปเดต
1. แท็บ Actions → เลือก workflow ชื่อ selftest → Run workflow แล้วอ่านผล (PASS/WARN/FAIL) ของ: ANTHROPIC_API_KEY, GDELT, Claude API, Claude web search, Yahoo, Telegram
2. แท็บ Actions → ดูว่า scheduled/watch ขึ้นรายการรันหรือไม่ ถ้าไม่เคยรันเลย: เปิดใช้ Actions ในแท็บ Actions (repo ใหม่/fork มักปิดไว้) และ workflow ต้องอยู่ใน default branch; repo สาธารณะที่ไม่มีกิจกรรมนาน GitHub อาจปิด schedule อัตโนมัติ ให้กด Enable/Run workflow ใหม่
3. ถ้ารันแล้วขึ้นแดง: เปิด log ดูบรรทัดสุดท้าย (ระบบจะบอกข้อผิดพลาดแรกของรอบ และส่ง Telegram ถ้าตั้งไว้) สาเหตุที่พบบ่อยคือ API key ผิด/ไม่มีเครดิต, GDELT ล่ม/ช้า, ไม่ได้เปิด web search (ตั้ง WEB_SEARCH=0 หรือเปิดใน Anthropic Console — ระบบจะลองใหม่แบบไม่ใช้ web search ให้เองอัตโนมัติ)
4. ถ้า Actions ขึ้นเขียวแต่หน้าเว็บไม่เปลี่ยน: ตรวจว่า Pages เสิร์ฟจาก branch เดียวกับที่บอทคอมมิต (ไฟล์ data/data.json ต้องมี last_ok) และกด Ctrl+F5
5. บรรทัดสถานะใต้หัวข้อหน้าเว็บบอกชัด: ยังเป็นข้อมูลตัวอย่าง / เนื้อหาอัปเดตล่าสุดกี่โมง / รอบล่าสุดล้มเหลว และรายการ 🔔 แสดงผลแต่ละรอบ (สำเร็จกี่ประเทศ ผิดพลาดกี่ประเทศ)
- รอบ scheduled ที่ไม่สำเร็จเลยสักประเทศ จะทำให้ workflow ขึ้นแดงและแจ้ง Telegram (ก่อนหน้านี้ข้อผิดพลาดถูกข้ามเงียบๆ)
- หน้าเว็บที่เผยแพร่ในแชต Claude (ลิงก์ artifact) เป็นต้นแบบข้อมูลตัวอย่างและจะไม่อัปเดตเอง ต้องใช้ชุดไฟล์ในซิปที่โฮสต์เองเท่านั้น
